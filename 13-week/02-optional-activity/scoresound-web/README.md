# scoresound-web

Frontend Angular de la semana 12. Hace login contra la API de ScoreSound, guarda el token y muestra la lista de usuarios (endpoint protegido).

## Uso

1. Arrancar la API (`scoresound-api`) en http://localhost:8080.
2. En esta carpeta:

```
npm install
npm start
```

3. Abrir http://localhost:4200 e iniciar sesión con `admin` / `admin123`.

La URL de la API está en `src/app/api.config.ts`.
